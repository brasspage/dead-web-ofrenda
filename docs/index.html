Ofrenda for the Dead Web

🕯️🌼🕯️

Every site here died. The Internet Archive kept a copy of its home page from before it died. An open-weight model, Gemma 4, read that page and wrote the site a calavera: the teasing little poem you write for the dead on Día de los Muertos.

How the facts are kept honest

  • The date of death comes from a web search. The model must copy the words that state it from one result. Code checks that those words are in that result and name the day and month, and the "Date source" link goes to that result.
  • The last words are copied from the archived page. Code checks them word for word against the page text (case and spacing aside), and drops them if they are not there.
  • The summary and the cause of death are the model's own words from the page and the search results. Code does not check them.
  • The calaveras are poems by the model. They are meant to tease, not to be cited.
